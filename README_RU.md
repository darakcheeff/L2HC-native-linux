## 🎧 Описание проекта

**L2HC-native-linux** — это самостоятельная, нативная реализация аудиокодека **Huawei L2HC** (Low-Latency High-Definition Codec) на языке Си без внешних бинарных зависимостей. Обеспечивает беспроводную передачу студийного звука высокого разрешения (**до 960 кбит/с, 24 бит / 48–96 кГц**) в Linux через **PipeWire** и **BlueZ**.

В отличие от решений на базе эмуляции (QEMU + Android Bionic libc), кодек **L2HC-native-linux** работает **напрямую на архитектуре x86_64**. Никаких эмуляторов, фоновых сервисов и закрытых ARM-библиотек не требуется.

## ✨ Ключевые возможности

- **100% Native C99:** Чистая реализация математического аппарата кодека по реверс-инжинирингу оригинальных библиотек Huawei.
- **Высочайшая производительность (>40x Realtime):** Кодирование 10-мс фрейма занимает всего ~0.23 мс (<2.5% нагрузки одного ядра современного CPU).
- **Фрагментация 960 кбит/с по спецификации EMUI:** Точное формирование заголовков фрагментов пакетов (`layer_specific = 1` для 1-го фрагмента, `0` для 2-го фрагмента) в соответствии со стеком Huawei Fluoride (`L2hcConstructMtuOrganizedBtBufferRecords`), что полностью устраняет фоновый треск и искажения звука на FreeBuds Studio и FreeBuds Pro.
- **Защита очереди передачи TXQ (по алгоритму EMUI):** Воссоздан контроллер очереди передачи Huawei (`L2hcA2dpSetTransmitQueueLength`): отслеживает нагрузку на буфер сокета (`unsent > 2400` байт ≈ 2 пакета) и при радиоколлизиях в эфире 2.4 ГГц кратковременно сбрасывает битрейт на 640 кбит/с (1 нефрагментированный пакет), предотвращая отбрасывание пакетов ядром (`EAGAIN`), а затем автоматически восстанавливает полные 960 кбит/с в течение 100 мс. Обеспечивает монолитный звук без заиканий точно так же, как на смартфонах Huawei.
- **Точное распределение битов (`EncodeMDCTCountBits`):** Строгий цикл обратной связи полностью исключает переполнение буфера и обрезку частотного диапазона.
- **Адаптивное спектральное квантование:** Динамический подбор таблиц Хаффмана для 1-, 2- и 4-кортежей с упаковкой тонких резидуалов (`PackMDCTResBranch`).
- **Универсальная поддержка PipeWire (0.3, 1.0, 1.2, 1.4, 1.6):** Поставляется как в виде Multi-ABI пакета с автоопределением версии, так и в виде DKMS-пакета для локальной перекомпиляции.
- **Интеграция с рабочим окружением:** Полная поддержка WirePlumber, Blueman, `pavucontrol`, регуляторов громкости GNOME, MATE, KDE.
- **Поддерживаемые профили:**
  - `L2HC (960 kbps)`: Студийное аудиофильское качество (скорость передачи 120 КБ/с).
  - `L2HC (640 kbps)`: Очень высокое качество с повышенной дальностью связи.
  - `L2HC (480 kbps)`: Высокое разрешение.
  - `L2HC (320 kbps)`: Высокое качество, максимальная стабильность радиоканала.
  - `L2HC (Auto)`: Адаптивный битрейт (ABR) в зависимости от радиоусловий.

## 📦 Быстрая установка (.deb)

Скачайте актуальные `.deb` пакеты со страницы [Releases](https://github.com/darakcheeff/L2HC-native-linux/releases/latest):

### Вариант 1: Multi-ABI Fat-пакет (Рекомендуется — оффлайн-установка)
Содержит скомпилированные модули для PipeWire **0.3.x, 1.0.x, 1.2.x, 1.4.x и 1.6.x**. При установке скрипт автоматически определяет установленную версию PipeWire и подключает нужный бинарник:

```bash
wget https://github.com/darakcheeff/L2HC-native-linux/releases/download/v1.1.1/l2hc-native-linux-multiabi_1.1.1_amd64.deb
sudo dpkg -i l2hc-native-linux-multiabi_1.1.1_amd64.deb
```

### Вариант 2: DKMS-пакет локальной сборки
Компилирует SPA-плагин локально под установленные заголовки PipeWire и автоматически пересобирается при обновлениях системы:

```bash
wget https://github.com/darakcheeff/L2HC-native-linux/releases/download/v1.1.1/l2hc-native-linux-dkms_1.1.1_all.deb
sudo dpkg -i l2hc-native-linux-dkms_1.1.1_all.deb
```

## 🎧 Важно: первоначальная настройка наушников (FreeBuds)

Если при сопряжении наушников с Linux в списке кодеков видны только **SBC** и **AAC**:

1. Подключите наушники к приложению **Huawei AI Life** (на смартфоне с Android/iOS) или смартфону Huawei.
2. В настройках наушников перейдите в раздел **«Качество звука» / «Аудиокодек Bluetooth»** и включите переключатель **«Smart HD / L2HC»**.
3. Наушники сохранят эту настройку в энергонезависимой памяти и при подключении к компьютеру с Linux станут анонсировать свой вендорный L2HC endpoint (`Vendor ID: 0x027D`).

## 🛠️ Сборка из исходников

### Зависимости для сборки

```bash
sudo apt-get install build-essential libspa-0.2-dev
```

### Сборка и запуск тестов:

```bash
git clone https://github.com/darakcheeff/L2HC-native-linux.git
cd L2HC-native-linux
make check
```

### Сборка пакетов:

- **Сборка Multi-ABI пакета:**
  ```bash
  ./scripts/build_multiabi_deb.sh
  ```
- **Сборка DKMS-пакета:**
  ```bash
  ./scripts/build_dkms_deb.sh
  ```

Готовые пакеты будут сформированы в каталоге `dist/`.

## 🔬 Архитектура и сигнальный тракт

```
  PCM звук (24 бит / 48–96 кГц Stereo)
                 │
                 ▼
  [ Непрерывное Low-Delay Оконное взвешивание ] <-- MDCT_HRA_WINDOW_480 / 960 (10мс)
                 │
                 ▼
      [ Быстрое Type-IV MDCT ]                 <-- 480 / 960 частотных бинов
                 │
                 ▼
  [ Энергии полос и масштабные коэффициенты ]  <-- 32 подполосы по шкале Барка
                 │
                 ▼
      [ Cost-Based Mid/Side анализ ]           <-- Динамический выбор L/R или M/S
                 │
                 ▼
    [ Быстрый поиск базового гейна ]           <-- Бинарный поиск global_gain
                 │
                 ▼
  [ Точный цикл обратной связи по битам ]      <-- EncodeMDCTCountBits (ноль переполнений)
                 │
                 ▼
  [ Квантование и кодирование Хаффмана ]       <-- 4tup, 2tup, 1tup + знаки
                 │
                 ▼
   [ Упаковка тонких резидуалов ]              <-- PackMDCTResBranch
                 │
                 ▼
   [ L2CAP MTU фрагментация и контроль TXQ ]   <-- layer_specific заголовки и авторазгрузка
                 │
                 ▼
       Bluetooth радиомодуль (HCI)             <-- Чистый поток 960 кбит/с (120 КБ/с)
```
